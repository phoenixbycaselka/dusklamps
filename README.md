# Dusk Lamps
A small daily lights-out puzzle. Tap a lamp to toggle it and its four neighbours; light them all.
Puzzles are generated from a date seed (same puzzle for everyone each day), always solvable, with a par move count. Sizes 4–6.

Play: https://phoenixbycaselka.github.io/dusklamps/

`node test.js` checks solvability and determinism. MIT licence. No dependencies.
